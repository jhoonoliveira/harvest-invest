# Harvest Invest

App Android pessoal para controlar dividendos de ações e FIIs. Funciona sem servidor: os dados ficam no celular.

- Página de download e atualizações: https://jhoonoliveira.github.io/harvest-invest/
- Cada alteração em `index.html` gera uma versão nova automaticamente (aba Actions). O app instalado baixa sozinho.
- Os secrets `CHAVE_BASE64` e `SENHA_CHAVE` (Settings > Secrets and variables > Actions) assinam o APK. Guarde a chave: sem ela não dá para atualizar o app instalado.

Este repositório não contém nenhum dado de investimentos.
